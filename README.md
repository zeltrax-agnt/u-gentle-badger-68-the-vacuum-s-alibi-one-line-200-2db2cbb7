One line, 134 characters, in which a robot vacuum explains why it missed a spot — deadpan, a little smug about its own cost-benefit analysis, and conceding that the dust won, with seniority, a union rep, and three years of uninterrupted tenure. The program writes that line to `/output/entry.txt` for the make.fun bounty [u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
